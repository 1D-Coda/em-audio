Reference results for release v1.0.8
commit at freeze time: 3a9ddabf94eb843349b7001ee13aaa1ccf421c99

These are the values tools/verify_reproduction.py holds a reproduction
to. They are a frozen copy of results/machine_readable/ as of the
release above, and are refreshed only when a new release is cut. The
copy exists so that a reproducer working from a source archive, which
has no git history, still has something to compare against.

The commit recorded here is the one that was current when the snapshot
was written, which is necessarily the parent of the commit that stores
it. A file cannot contain the hash of the object that contains it.
